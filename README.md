### What I'm building in the open
**[Promptier](https://www.npmjs.com/package/@cachai/promptier-react-sdk)** — an editor for LLM
prompts, published on npm as [`@cachai/promptier-core-editor`](https://www.npmjs.com/package/@cachai/promptier-core-editor)
(framework-agnostic Custom Element, built on ProseMirror, with the prompt-format codec usable
server-side) and [`@cachai/promptier-react-sdk`](https://www.npmjs.com/package/@cachai/promptier-react-sdk)
(React, with toolbar and outline). The editor understands the `{{ variables }}` of your template and
the tools your model can call, without rendering either. ESM + CJS + TypeScript types.
